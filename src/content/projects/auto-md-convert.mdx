## Why I built this

My coding agent kept missing context that only existed in email threads. I wanted one gesture to fix that: drag the message out of Outlook, drop it in the project's folder, and the agent has it.

## How it works

- **You choose the folders.** A background watcher starts at login and converts files only in folders you enable. Anything dropped elsewhere stays untouched.
- **One Markdown file per email.** Subject, sender, recipients and date go in YAML front matter, followed by the body and every attachment, converted inline.
- **Not just email.** Word, PowerPoint, Excel, PDF, HTML, RTF, CSV and EPUB go through the same drop, and a Finder Quick Action converts a file anywhere on demand.
- **Originals are kept.** The source moves to an archive folder next to the Markdown, so nothing is lost.
- **No mail access and no plugins.** The unit of input is a file you drag out of an app, so it doesn't need to script Outlook or log in to anything.

## What made it harder than it looks

A file watcher is easy until the files are real. A file can still be changing while it's read, so those wait for a later scan. Name collisions get a numeric suffix rather than overwriting, including repeat drops of the same email. Complete output is published atomically where the filesystem supports it, and failed conversions keep the source and retry.

Email is its own rabbit hole. Attached emails are converted recursively, up to ten levels, with a visible notice at the limit. An attachment that can't be converted still appears with its name, its size and a notice, and the rest of the message carries on.
