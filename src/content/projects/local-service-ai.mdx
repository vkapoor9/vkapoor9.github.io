## What it is

Three small servers, one idea: most local service businesses lose money in the gaps, not the jobs. Each tool closes one gap.

- **Sub60** answers every missed call and web lead in seconds, qualifies the job one question at a time, and books it.
- **ReviewPilot** drafts a response to every review tuned to its rating (grateful for fives, empathetic and offline for ones, honest for threes) and runs campaigns to earn new ones.
- **ReviveAI** works the dormant database, opening with a segment-specific message (past customer, cold lead, abandoned quote) and walking a reply toward a rebooking.

## How it works

- **Deterministic by default.** The conversation core is a plain state machine, so the demo runs fully without an API key. That makes it reliable and easy to reason about.
- **LLM as a layer, not a crutch.** Set one environment variable and OpenAI, or a local MLX server, rewrites the prose to feel human. The booking and routing logic never moves into the model.
- **Zero-dependency stack.** Each tool is a Node HTTP server with a JSON store and a vanilla-JS dashboard that seeds realistic demo data on first run.

## Why it's here

This is the part of "applied AI" that isn't the model. Deciding where a deterministic rule is safer than a generation, and where the LLM actually earns its place, is most of the job. These are working prototypes, not a hosted product.
