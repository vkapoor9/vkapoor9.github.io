## What it is

A native macOS markdown editor for the people who actually live in markdown: long documents, tables, code blocks, and clean typography. Editable text on the left, live-rendered preview on the right in a GitHub-style theme, with mermaid diagrams and syntax-highlighted code.

## How it works

- **Native editing.** An `NSTextView` wrapper gives real undo, a find bar, and a proper monospaced editor; a file-service actor handles open and save with security-scoped bookmarks.
- **Live preview.** A `WKWebView` loads a self-contained HTML shell that inlines marked.js, mermaid.js, and highlight.js, then receives debounced markdown as you type. No network calls, everything bundled.
- **Recents and settings.** A recents sidebar persists files via security-scoped bookmarks; theme, font, and spacing live in UserDefaults and apply to the preview instantly.

## Why it's here

A small project, but a tidy proof that the AI workflow extends past the web. SwiftUI is a good test bed for whether an LLM can carry serious work into a typed, rapidly-evolving native framework. It builds clean and runs on macOS; it isn't distributed.
